🚦 Traffic Data Analysis

📌 Project Overview

This project analyzes traffic data to identify patterns, peak traffic hours, congestion trends, and factors affecting traffic flow. The objective is to extract meaningful insights from traffic datasets and support data-driven transportation planning.

🎯 Objectives
Analyze traffic volume across different time periods.
Identify peak congestion hours.
Visualize traffic patterns using charts and graphs.

📂 Dataset
The dataset contains traffic-related information such as:
Junction id,
Timestamp,
Vehicle Count,
Average Speed,

🛠️ Technologies Used
Pandas
Matplotlib
Seaborn
Jupyter Notebook
